Vitalis: AI-Powered Personal Health Manager

🌟 Project Overview

Vitalis is a modular, AI-powered personal health management application designed to give users control and insight into their well-being. Built leveraging the power of Google AI Studio and the Gemini API, Vitalis provides intelligent tracking, personalized guidance, and secure document storage for a comprehensive health experience.

The application is built primarily with TypeScript and client-side HTML/JavaScript, ensuring a robust and performant user interface.

💡 Key Features

Vitalis offers a range of tools, many of which are enhanced by integrated artificial intelligence:

Period Tracker: Log, visualize, and calculate key statistics like cycle length and average duration.

Symptom Logging: Easily record and track various physical and mental health symptoms over time.

Medication Management: Keep track of current prescriptions, dosage schedules, and reminders.

AI-Powered Health Guides: Access personalized diet, exercise, and wellness recommendations generated by the integrated AI model.

Secure Document Storage: Safely upload and manage important medical records, test results, and prescriptions.

🛠 Technology Stack

Language: TypeScript

Frontend: HTML, CSS, and Vanilla JavaScript (compiled via TypeScript)

AI Backend: Google AI Studio / Gemini API

Package Management: npm
